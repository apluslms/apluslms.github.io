### New features and changes

#### A+

* Add submission invalidation feature [#1479](https://github.com/apluslms/a-plus/issues/1479)
* Add questionnaire reset functionality [#494](https://github.com/apluslms/a-plus/issues/494)
* Add course audience tag filter for the frontpage and course archive [#580](https://github.com/apluslms/a-plus/issues/580)
* Add course navigation to the 403 and 404 error pages [#1300](https://github.com/apluslms/a-plus/issues/1300)
* Add a badge to the module list for displaying the read open time [#1540](https://github.com/apluslms/a-plus/issues/1540)
* Add checks for invalid enrollment dates [#188](https://github.com/apluslms/a-plus-rst-tools/issues/188)
* Add fixes for height and length options in text fields [#153](https://github.com/apluslms/a-plus-rst-tools/issues/153)
* Add performance optimizations for the participants list page [#904](https://github.com/apluslms/a-plus/issues/904)
* Only display the point goal button if a module is accessible [#1537](https://github.com/apluslms/a-plus/issues/1537)
* Fix inefficient checking of teacher status [#1549](https://github.com/apluslms/a-plus/issues/1549)
* Remove the unused LearningObjectDisplay model to improve performance and reduce database usage [#1547](https://github.com/apluslms/a-plus/issues/1547)
* Fix unnecessary GraderUser token admin-level read permissions
* Retry transient grading poll failures
* Fix cache bugs
