### New features and changes

#### A+

* Upgrade to Django 5.2 LTS
* Add a UI for batch assessment in the participants page [#1513](https://github.com/apluslms/a-plus/issues/1513)
* Don't retain inputs for feedback exercises
* Add template information for when grader feedback has been received
* Redirect to homepage page after logout
* List hidden modules to teachers and admins in the API [#1522](https://github.com/apluslms/a-plus/issues/1522)
* Create an API endpoint and permission for fetching all current teachers [#1503](https://github.com/apluslms/a-plus/issues/1503)

#### MOOC-Grader

* Upgrade to Django 5.2 LTS
* Add new noSubmission exercise view type [#1526](https://github.com/apluslms/a-plus/pull/1526)
* Fix a bug with quiz hints when using :randomized: option [#160](https://github.com/apluslms/mooc-grader/issues/160)

#### Git Manager

* Upgrade to Django 5.2 LTS
* Add support for new 'noSubmission' exercise view type [#1526](https://github.com/apluslms/a-plus/pull/1526)

#### MOOC-Jutut

* Upgrade to Django 5.2 LTS
* Filter "Show all feedback for this exercise" [#128](https://github.com/apluslms/mooc-jutut/issues/128)
* Fix student feedback message not being cleared on submit
* Implement HTML sanitization for student and teacher messages [#132](https://github.com/apluslms/mooc-jutut/issues/132)
* Do not auto-grade empty messages if previous unread feedback exists [#121](https://github.com/apluslms/mooc-jutut/issues/121)
* Add "Add deadline deviation" button
